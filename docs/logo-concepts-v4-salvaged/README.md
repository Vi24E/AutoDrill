# AutoDrill logo concepts v4 — salvaged

The original `docs/logo-concepts-v4/` files were deleted before being committed to Git, so their exact byte contents were not recoverable.

These three SVGs reconstruct that v4 iteration from the surviving conversation record and the original user sketch. The defining geometry is preserved: two intentionally skewed quadrilateral metal parts followed by a separate triangular drill tip, all directed toward the upper right.

- `01-metal-drill-faithful.svg` — reconstructed base shape
- `02-metal-drill-tip-accent.svg` — same geometry with tip accent
- `03-metal-drill-favicon.svg` — small-size/favicon-oriented reconstruction
