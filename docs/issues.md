# AutoDrill — Issues

AutoDrillの **Issue / backlog の唯一のsource of truthは [GitHub Issues](https://github.com/Vi24E/AutoDrill/issues)** とする。

このファイルはrepository内の入口だけを提供し、Issue本文・状態・priority等を複製しない。新規Issueの作成、更新、Close、再OpenはGitHub Issues上で行う。

- Canonical backlog: [Vi24E/AutoDrill Issues](https://github.com/Vi24E/AutoDrill/issues)
- 2026-08-30以前のMarkdown backlog snapshot: [`archive/issues-md-backlog-2026-08-30.md`](archive/issues-md-backlog-2026-08-30.md)
- dated audit文書は発見時点の証拠・調査記録であり、current backlogのsource of truthにはしない。

## Pre-release compatibility policy

pre-release compatibilityに関する現行方針は [`principles.md`](principles.md) と [`architecture/`](architecture/) を正とする。個別の未解決作業はGitHub Issuesで追跡する。
